# Shreyas S Bhat — Builder OS Portfolio

A responsive static portfolio with:
- Developer OS system dashboard
- Interactive featured-project case studies
- Project architecture / build-process section
- GitHub Lab
- Internship experience
- Build timeline
- Command palette (`Ctrl/Cmd + K`)
- Random project / "Surprise me" interaction
- Responsive layout

## Run
Open `index.html`, or run:
`python -m http.server 5500`

## Deploy
Deploy the folder to Vercel, Netlify, GitHub Pages, or another static host.
